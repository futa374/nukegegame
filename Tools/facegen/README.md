# 頭部モデルの質感を作る手順

`Assets/Models/monden_head.obj` に貼る一式（アルベド・法線・AO・粗さ）と、
別メッシュとして切り出した眼鏡フレームを作るためのスクリプト群。
番号順に実行すれば再現できる。

## 入力

| 何 | どこ | 備考 |
|---|---|---|
| 高解像度スキャン | `monden_head_noneck.stl`（96,614頂点） | リポジトリには含めない（15MB超） |
| 正面写真 | 手元の1枚 | リポジトリには含めない |
| 間引き版メッシュ | `Assets/Models/monden_head.obj`（13,317頂点） | 出力にも使う |

高解像度スキャンと写真はリポジトリに置いていない。前者は容量、後者は素の顔写真だから。
生成物（テクスチャ）だけを成果物として置いている。

## 考え方

この頭の UV は球面投影で、中心から見た向き (u, v) だけで決まる。
つまり表面は「向き → 中心からの距離 r」という地形図として扱える。
地形図があれば、傾きから法線が、地平線の高さから AO が求まる。
レイトレーサを書かずに済むのは、UV の張り方がこの形だからこそ。

同時に、この UV には避けられない欠点がある。
向きが同じなら距離が違っても同じ座標になるので、
眼鏡フレームと、そのすぐ裏の肌が、まったく同じテクセルを共有してしまう。
だから眼鏡は「描く」のではなく「置く」。フレームを別メッシュとして切り出し、
黒いマテリアルでかぶせている（01）。

## 手順

| # | スクリプト | すること |
|---|---|---|
| 01 | `01_extract_glasses.py` | スキャンから眼鏡フレームの面だけを切り出し、`monden_glasses.obj` を書く |
| 02 | `02_fit_photo.py` | 写真の中の眼鏡とモデルの眼鏡を手がかりに、写真と顔の対応を薄板スプラインで求める |
| 03 | `03_photo_albedo.py` | 写真から陰影・皮脂の照り・白い点を落として、素の色にする |
| 04 | `04_radius_maps.py` | 高解像度版と間引き版の地形図（半径マップ）を作る |
| 05 | `05_project_to_uv.py` | 写真を UV へ投影し、届かない所は肌色でなだらかに埋める |
| 06 | `06_bake_ao.py` | 地形図の上で地平線を測り、AO を焼く |
| 07 | `07_bake_normal.py` | 間引きで失われた凹凸＋毛穴の肌理を法線マップにする |
| 08 | `08_smoothness.py` | 皮脂の照りの分布と、角膜の強い照り返しを描く |
| 09 | `09_despeckle.py` | アルベドに残った白い点を消す（キャッチライトは残す） |
| 10 | `10_flatten_frame.py` | 頭のメッシュから眼鏡の出っ張りを均す |
| 11 | `11_despike_mesh.py` | スキャンの棘を取る |

## 落とし穴

**目の位置は、レンズの穴の「向き」に置いてはいけない。**
球面 UV は中心から見た向きで決まるが、目はレンズより奥の肌にある。
同じ向きの肌の点は、レンズより中心軸に寄った位置——内側かつ下——に来る。
正面から見て重なる位置に描くには、向きではなく (x, y) を合わせる（05）。

**法線マップは、間引いたメッシュの「面」と比べてはいけない。**
Unity は頂点法線を滑らかに補間して陰影を付けるので、
比べる相手は三角形の平面ではなく、その滑らかな面でなければならない。
面と比べると三角形の切り替わりが段差として焼き付き、顔じゅうが割れて見える（07）。

**白い針のような三角形は、テクスチャではなく形の問題。**
眼鏡フレームは厚さ数ミリの薄い殻で、13,000頂点まで間引くと表と裏がほぼ同じ場所に来る。
潰れた三角形は法線が定まらず、光を拾って白く光る（10）。
